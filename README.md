# Arun Prajapati Portfolio

A standalone Next.js recreation of the supplied Emergent portfolio screenshots.

## Run locally

Requirements:
- Node.js 18.18+ (Node 20+ recommended)

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build

```bash
npm run build
npm start
```

## Customize

Most portfolio content is in `app/page.tsx`.

- Update experience
- Update skills
- Update projects
- Update phone/email/LinkedIn
- Replace the hero image at `public/images/hero-abstract.jpg`
- Add your real resume as `public/resume.pdf`

The visual theme is in `app/globals.css`.

## Important

The supplied screenshots contain placeholder experience/education/project text. Those placeholders are preserved so the layout matches the screenshots. Replace them with your actual details.
